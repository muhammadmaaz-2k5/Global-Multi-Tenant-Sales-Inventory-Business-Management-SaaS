# SPRINT 5: Point of Sale (POS) Interface
**Goal:** Provide a fast, responsive interface for cashiers to process sales.

- [x] Story 5.1: Search for products by name or barcode.
- [x] Story 5.2: Add items to cart and see subtotal, tax, total.
- [x] Story 5.3: Apply line-item or cart discount.
- [x] Story 5.4: Suspend a sale and retrieve it later.
